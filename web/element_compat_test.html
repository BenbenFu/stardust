element 维度兼容性重构 · 可视化验证

每张卡设定 --card-bg/--card-text/--card-accent/--card-muted 四个调色槽。背景类装饰走共享 14 槽画布，文本类走专属伪元素。

A. 四装饰全部独立（单元素）

角标·圆印
corner=circle_stamp
背景·点阵
bg=dot_grid
边缘·方括号
edge=bracket_frame
边缘·齿孔
edge=stamp_perforation（四边镂空，独立）
浮动·圆
float=floating_circle

B. 四装饰全叠加（角标+背景纹+边缘+浮动 同时）

谜语卡·叠加
折角+点阵+方括号+浮动圆，四者共存
corner=page_fold + bg=dot_grid + edge=bracket_frame + float=floating_circle
便签·叠加
点状角标+横线+胶带纹+散点
corner=dot_status + bg=horizontal_lines + edge=tape_stripe + float=scatter_dots

C. 文本装饰（专属伪元素）与背景装饰共存

特惠卡
丝带(::after) + 精细方格背景
corner=corner_ribbon ::after + bg=fine_grid
复古终端
TAMAGOTCHI(::before) + 扫描线
float=tamagotchi_label ::before + bg=terminal_scanlines
Art Deco
菱形(::before+::after) + 邮票齿孔
float=art_deco_diamond 双伪元素 + edge=stamp_perforation

D. 边缘类正交（clip / outline 不抢背景与伪元素）

切角
clip-path + 渐变叠层
edge=notched_corner + bg=gradient_overlay

E. 位置锚点演示（同一装饰贴不同角，无需另建条目）

下面 4 张卡都是 同一个 corner_ribbon，仅靠引擎注入的 --el-corner-* 位置变量切换到四角；切角卡演示 data-style-element-edge-anchor 切到左下角。

丝带·右上(原生)
corner=corner_ribbon（无变量，原生右上）
丝带·左上
corner=corner_ribbon（注入左上变量）
丝带·左下
corner=corner_ribbon（注入左下变量）
丝带·右下
corner=corner_ribbon（注入右下变量）
切角·左下
data-style-element-edge-anchor=bottom-left
edge=notched_corner（锚点切到左下角）
