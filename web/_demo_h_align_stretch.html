h_align = 撑满(stretch) · 横排「栏=左对齐」下能否覆盖左对齐

复现场景：栏-水平对齐 = 左对齐（绿色槽位被 justify-items:stretch 撑满整宽，文字默认左对齐）。
参照 = 字段不覆盖 → 文字左对齐；居中 / 靠右 = 文字立刻变居中/右对齐（单行 text-align 即生效）→ 肉眼可见覆盖；
撑满(旧) = 仅 text-align:justify，单行(=最后一行)默认不 justify → 文字仍停左边、与参照不可区分；
撑满(新) = justify + text-align-last:justify → 单行也两端对齐、字距沿行宽散开 → 同样肉眼覆盖左对齐。
