## 题一：bg_pattern · `grain_noise`（胶片 / 纸张颗粒噪点）

### 设计目标
一种细微的颗粒 / 噪点纹理，给卡片增加「胶片 / 旧纸 / 磨砂」质感。当前 `bg_pattern` 已有 dot_grid、fine_grid、horizontal_lines、gradient_overlay、terminal_scanlines、starfield，**没有噪点类**。这是通用底纹，几乎任何主题都能复用。

### 硬性要求
1. 子维度 `bg_pattern`，`value='grain_noise'`。实现方式：**背景类**（占 bg 槽，不抢伪元素、不写 mask/clip）。
2. 噪点必须用 **SVG `feTurbulence` 生成的 data-URI** 作为背景图像（不是 CSS 渐变模拟），放进 `--el-bg-1`（bg 组槽位）。
3. 必须自带**逐字一致的 14 槽主合成块**（手册 §3.1 契约块，机械复制）。
4. 只 `SET` 自己组的 `--el-bg-*`，**绝不许跨组写槽**（不要碰 `--el-corner-*` / `--el-edge-*` / `--el-float-*`）。
5. 颜色合规：噪点本征灰阶（黑 / 灰半透明斑）可保留（属纹理本身）；若想让噪点着色，**必须引用 `--card-accent` / `--card-muted` 等配色槽，禁止写死 hex 设计色**。
6. `var()` 之外**不得出现裸 CSS 关键字**（尤其 `background-repeat` 里不能夹裸 `repeat`）。
7. 噪点要「细而淡」：tile 尺寸建议 120–220px，整体不喧宾夺主。

### 引用手册条款
§1.3（14 槽画布契约）、§2 机制 A（变量命名）、§3.1（背景类模板）、§1.5（配色槽）。

### 交付物
1. `INSERT` 语句骨架（`style_element_options`，按表结构填 `sub_dim/value/label/css_template` 等字段）。
2. `css_template` 完整文本（含契约块）。

### 评分细则（做到这些即合格）
- 选择器 `.gallery-card[data-style-element-bg="grain_noise"]` 正确（前导 `.` 不漏）。
- 携带完整 14 槽主合成块，顺序 `corner,edge,bg,float`，四属性全 `var()` 引用带兜底。
- `--el-bg-1` 是合法的 SVG `feTurbulence` data-URI；`--el-bg-size-1/pos-1/rep-1` 合理。
- 不跨组写槽；着色时引用配色槽而非写死设计色；无裸关键字。
- 未使用的 bg-2..4 / 其它组变量留 `none`/默认，不污染。

### 常见错误（判错项）
- 漏主合成块 → 画布不显示（最致命）。
- 在 `var()` 外多拼裸 `repeat` → 整条 `background-*` 回退默认 repeat → 噪点平铺满卡。
- 把噪点图像写进 `--el-corner-1` 或 `--el-float-1` → 跨组写槽，连坐其它装饰。
- 写死 `#000`/`#fff` 作为强调 / 底色（纹理灰阶除外）。
- 用 CSS 渐变「假装」噪点而非 SVG turbulence（不满足「噪点」本质，验收不过）。

## 题二：floating_deco · `wax_seal`（火漆印章）

### 设计目标
一枚实心圆形「火漆印章」浮于卡片之上（带内圈、轻微立体阴影），作点缀强调。当前 `floating_deco` 只有 floating_circle（淡环）、scatter_dots（散点）、art_deco_diamond（满宽菱形带），**没有实心徽章类**。火漆印章是手账 / 信笺 / 限定款的通用点缀。

### 硬性要求
1. 子维度 `floating_deco`，`value='wax_seal'`。
2. 实现方式：**隔离层**（参照 floating_circle 的现行方案，不要走 14 槽画布）。
3. 用 `.card-deco-layer::after` 承载（`.card-deco-layer::before` 已被 floating_circle 占用；`floating_deco` 单选维度保证二者不会同卡，但按约定走 `::after` 最干净）。
4. 定位必须读引擎发射的**锚点变量** `--el-float-pos-{top,right,bottom,left}` 与 `--el-float-pos-tf`（`var(..., 兜底)` 消费），**不要写死位置、不要自己发明变量名**。
5. 形状用 `radial-gradient` / `box-shadow` 画实心圆 + 内圈，颜色引用 `--card-accent`（印体）与 `--card-bg`（内圈细节），**禁止写死 hex**。
6. `content:""`、`position:absolute`、`pointer-events:none`、`z-index` 与 floating_circle 同级（≥4）。
7. **不要**在卡片根写 `background-image`（不抢画布 float 槽）。

### 引用手册条款
§1.2（三类实现）、§1.4（伪元素分配 + floating_circle 隔离范式）、§2 机制 B（锚点变量）、§1.5（配色槽）。

### 交付物
1. `INSERT` 语句骨架。
2. `css_template` 完整文本。

### 评分细则（合格）
- 选择器 `.gallery-card[data-style-element-float="wax_seal"] .card-deco-layer::after` 正确。
- 用 `::after`（非 `.gallery-card::before/::after` 被占用的伪元素；非画布 float 槽）。
- 四边定位 + transform 全部走 `--el-float-pos-*`，带合理兜底（默认贴一角 / 居中）。
- 颜色全引用配色槽；`content:""` / `pointer-events:none` / `z-index` 齐全。
- 不写画布 `--el-float-1`，不污染 14 槽画布。

### 常见错误（判错项）
- 写成画布 float 槽（SET `--el-float-1`）→ 重蹈 floating_circle 旧坑，与 bg 同卡被连坐。
- 用 `.gallery-card::before`（tamagotchi_label 预留）或 `::after`（corner_ribbon 占用）→ 伪元素撞车。
- 写死 `top:20px;right:20px` 而非读锚点变量 → 不支持 `floating_deco_pos` 8 锚点。
- 写死红色 / 金色等设计色（火漆红必须用 `--card-accent` 表达）。
- 漏 `content:""` → 伪元素不渲染。

## 题三：corner_badge · `photo_corner`（拍立得相角）

### 设计目标
卡片两个对角出现「相角 / 照片固定角」（小三角卡纸），营造拍立得 / 相框质感。当前 `corner_badge` 只有 circle_stamp（圆印章）、page_fold（折角 clip）、corner_ribbon（丝带 ::after）、dot_status（状态点），**没有三角相角**。这是相框 / 手账 / 复古照的通用边角装饰。

### 硬性要求
1. 子维度 `corner_badge`，`value='photo_corner'`。
2. 实现方式：**背景类**（占 corner-1、corner-2 两个角槽，与 circle_stamp 同类），用 `linear-gradient` 在两个对角画出三角形「相角」。
3. 必须自带**逐字一致的 14 槽主合成块**（含 corner-1,2 的 `var()` 引用）。
4. 只 `SET` 自己组的 `--el-corner-*`（两个角），**绝不许跨组写槽**，也不要用 `::before/::after`（那两个伪元素已预留 / 占用）。
5. 三角形用 `linear-gradient`（如 `135deg, var(--card-accent) 0 50%, transparent 50% 100%`）在角落画出；颜色引用 `--card-accent`（相角纸），**禁止写死 hex**。
6. 定位跟随 `corner_badge_pos` 的 8 锚点（通过引擎的 corner 锚点机制，**不要写死 `background-position`**；靠 `--el-corner-pos-{n}` 控制本槽位置）。
7. `var()` 外无裸关键字。

### 引用手册条款
§1.3（14 槽画布契约，corner 槽）、§2 机制 A（`--el-corner-*` 命名）、§3.1（背景类模板）、§1.5（配色槽）、§4（corner 锚点）。

### 交付物
1. `INSERT` 语句骨架。
2. `css_template` 完整文本。

### 评分细则（合格）
- 选择器 `.gallery-card[data-style-element-corner="photo_corner"]` 正确（前导 `.` 不漏）。
- 携带完整 14 槽主合成块（含 corner-1,2）。
- `--el-corner-1`、`--el-corner-2` 为 `linear-gradient` 三角形，`-size/-pos/-rep` 合理（两个对角，如左上 + 右下）。
- 只写 corner 组；颜色引用配色槽；无裸关键字；不碰伪元素。

### 常见错误（判错项）
- 漏主合成块 → 不显示。
- 把三角形写进 `--el-bg-1` 或 `--el-edge-1` → 跨组写槽。
- 用 `::after` 画相角 → 与 corner_ribbon 撞车（相角应走背景角槽，不是伪元素）。
- 写死 `background-position: top left` → 不支持 `corner_badge_pos` 8 锚点。
- 写死设计色。

## 通用红线（任一出现即不合格）
- 选择器漏前导 `.`（写成 `gallery-card[...]` 被当标签名 → 整条静默失效）。
- 背景类漏 14 槽主合成块（仅题一 / 题三）。
- 跨组写槽（corner/bg/edge/float 互相写）。
- `var()` 之外出现裸 CSS 关键字（如裸 `repeat`）。
- 写死设计色 hex（纹理中性灰阶 / 中性阴影除外）。
- 使用 `!important`。
