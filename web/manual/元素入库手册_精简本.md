# 卡片元素入库手册（精简本 · 当前状态）

> **读者**：要设计新元素（bg_pattern / corner_badge / floating_deco / edge_deco / header_deco / side_accent / divider 任一子维度）或改现有组件 CSS 的 agent。
> **前提**：你已会拼 `style_json`（不会先读同目录《拼装手册（精简本）》）。本手册只讲「怎么把一个新的视觉效果写进数据库、且不与其它装饰打架」。
> **你无数据库写权限**：本手册所有改动都产出 SQL，交用户审核执行。

---

## 1. 渲染器当前状态（写对 CSS 的前提）

### 1.1 四个装饰子维度各发射一个独立属性
`.gallery-card[data-style-element-corner=...]` / `[data-style-element-bg=...]` / `[data-style-element-edge=...]` / `[data-style-element-float=...]`。四者互不互斥，**可同时开启**。

### 1.2 三类实现方式
| 类 | 占用 | 例子 |
|---|---|---|
| **背景类** | 14 槽共享画布 | dot_grid、circle_stamp、bracket_frame、scatter_dots、starfield |
| **伪元素类** | 卡片伪元素（文字） | corner_ribbon(::after)、tamagotchi_label(::before)、art_deco_diamond(.card-deco-layer) |
| **正交类** | mask / clip | stamp_perforation(mask)、notched_corner(clip) |

（`floating_circle` 例外：隔离在 `.card-deco-layer::before`，见 §1.4）

### 1.3 共享 14 槽背景画布（背景类装饰能叠加的机制）
卡片根固定一块 14 槽背景画布，槽位顺序固定不可改：
```
角标 corner-1,2 | 边缘 edge-1,2,3,4 | 背景纹 bg-1,2,3,4 | 浮动 float-1,2,3,4
```

**当前机制：每个背景类模板各自携带一份逐字一致的 14 槽主合成块**（`background-image/-size/-position/-repeat` 各 14 个 `var()` 引用，顺序严格 `corner,edge,bg,float`，全部带兜底）。引擎 `BASE_CSS` 不含主合成（仅 `background: var(--card-bg)`），主合成由模板自带。

规则：
1. 主合成块全项目共享、逐字一致。任何背景类模板的主合成块必须与此契约逐字相同，不得增删、改顺序、在 `var()` 外夹裸关键字。
2. 槽位变量归各组私有：bg 装饰只 `SET` 自己的 `--el-bg-*`，corner 只 `SET` `--el-corner-*`，依此类推。**绝不许跨组写槽**。
3. 层叠原理：多个背景模板同卡时，`background-*` 同特异性、源码顺序后者胜属性；但因主合成逐字一致，胜出规则引用的仍是全部 14 槽变量，各模板只负责自己那组变量，故结果正确。任一模板偏离契约（缺主合成 / 改序 / 夹裸字）会连坐其它组图层。

### 1.4 伪元素分配 + floating_circle 隔离
| 伪元素 | 授权给 | 用途 |
|---|---|---|
| `.gallery-card::before` | tamagotchi_label | 顶部字样 |
| `.gallery-card::after` | corner_ribbon | 角标丝带 |
| `.card-deco-layer::before` / `::after` | art_deco_diamond | Art Deco 菱形带（双伪元素独占） |
| `.card-deco-layer::before` | floating_circle（隔离层） | 浮动圆。与 diamond 同属 `floating_deco` 单选维度，互斥，该伪元素对其永远空闲 |

文本类三者互不争用，可同时开 3 个。背景类与文本类天然正交，永远兼容。

### 1.5 配色槽位（禁止硬编码颜色）
palette 四个颜色列存的是色阶索引号（字符串），引擎按 tone/slot 解析后注入卡片根 CSS 变量；你**只引用这四色，禁止写死 hex**。

| 数据库列 | 注入变量 | 用途 |
|---|---|---|
| `bg` | `--card-bg` | 卡片底 / 浮层底 |
| `text_color` | `--card-text` | 主文字 |
| `accent` | `--card-accent` | 色条/边框/强调 |
| `muted` | `--card-muted` | 次要文字/描边 |

另有 `--card-accent-rgb` / `--card-bg-rgb`（如 `224,86,63`）供 `color-mix(in srgb, var(--card-accent) 60%, transparent)` 透明混色。

## 2. 变量命名规范（全项目唯一标准）

存在**两套独立机制**，禁止自行发明变量名。

**机制 A — 14 槽画布变量（背景类装饰写、主合成读）**
槽位顺序固定：`corner-1,2 | edge-1,2,3,4 | bg-1,2,3,4 | float-1,2,3,4`。每个槽位四件套：

| 槽位 | 图像 | 尺寸 | 位置 | 重复 |
|---|---|---|---|---|
| `corner-{1..2}` | `--el-corner-{n}` | `--el-corner-size-{n}` | `--el-corner-pos-{n}` | `--el-corner-rep-{n}` |
| `edge-{1..4}` | `--el-edge-{n}` | `--el-edge-size-{n}` | `--el-edge-pos-{n}` | `--el-edge-rep-{n}` |
| `bg-{1..4}` | `--el-bg-{n}` | `--el-bg-size-{n}` | `--el-bg-pos-{n}` | `--el-bg-rep-{n}` |
| `float-{1..4}` | `--el-float-{n}` | `--el-float-size-{n}` | `--el-float-pos-{n}` | `--el-float-rep-{n}` |

> 机制 A 的 `--el-float-{n}` 是画布上的 float 槽（被 scatter_dots 使用），与下方机制 B 的 `--el-float-pos-*` 隔离层变量**完全不同**。

**机制 B — 锚点定位变量（引擎发射、装饰消费，用于 8 锚点贴角/贴边）**
仅 `corner` 与 `float` 支持位置锚点，引擎在卡片根注入：

| 变量 | 含义 | 由谁设 | 由谁用 |
|---|---|---|---|
| `--el-{corner\|float}-anchor-pos` | 背景型装饰的 `background-position` 兜底串 | 引擎 | 背景型（circle_stamp / dot_status / scatter_dots） |
| `--el-{corner\|float}-pos-top/right/bottom/left` | 伪元素/隔离层四边定位 | 引擎 | 伪元素型（丝带/标签）与隔离层（floating_circle） |
| `--el-{corner\|float}-pos-tf` | 居中补偿 transform | 引擎 | 伪元素型 / 隔离层 |

> 机制 B 的 `--el-float-pos-top/right/bottom/left/tf` 是 floating_circle 隔离层定位变量，与机制 A 的 `--el-float-{n}` 画布槽互不干扰。模板只 `var(--el-xxx, 兜底)` 消费，**不得自己发明变量名**。

## 3. 标准入库 CSS 模板

可调色槽：`--card-bg` / `--card-text` / `--card-accent` / `--card-muted`（及 `-rgb`）。

### 3.1 背景类（必带逐字一致主合成 + 只 SET 本组变量）
最小可用模板（bg_pattern 为例）。`【契约块】` 是机械复制、逐字一致的 14 槽主合成，**所有背景类模板共用同一份，禁止手改**；`【本组变量】` 才是你每次要填的部分。

```css
.gallery-card[data-style-element-bg="your_value"] {
  /* ===== 【本组变量】人工填写：只写自己组的 --el-bg-* ===== */
  --el-bg-1: radial-gradient(circle, var(--card-muted,#ccc) 1px, transparent 1.6px);
  --el-bg-size-1: 16px 16px;
  --el-bg-pos-1: 0 0;
  --el-bg-rep-1: repeat;
  /* （bg-2..4 同理，不用则留空，主合成兜底 none 自动隐藏） */

  /* ===== 【契约块】机械复制，逐字一致，禁止改动/缺失 ===== */
  background-image:
    var(--el-corner-1, none), var(--el-corner-2, none),
    var(--el-edge-1, none), var(--el-edge-2, none), var(--el-edge-3, none), var(--el-edge-4, none),
    var(--el-bg-1, none), var(--el-bg-2, none), var(--el-bg-3, none), var(--el-bg-4, none),
    var(--el-float-1, none), var(--el-float-2, none), var(--el-float-3, none), var(--el-float-4, none);
  background-size:
    var(--el-corner-size-1, auto), var(--el-corner-size-2, auto),
    var(--el-edge-size-1, auto), var(--el-edge-size-2, auto), var(--el-edge-size-3, auto), var(--el-edge-size-4, auto),
    var(--el-bg-size-1, auto), var(--el-bg-size-2, auto), var(--el-bg-size-3, auto), var(--el-bg-size-4, auto),
    var(--el-float-size-1, auto), var(--el-float-size-2, auto), var(--el-float-size-3, auto), var(--el-float-size-4, auto);
  background-position:
    var(--el-corner-pos-1, 0 0), var(--el-corner-pos-2, 0 0),
    var(--el-edge-pos-1, 0 0), var(--el-edge-pos-2, 0 0), var(--el-edge-pos-3, 0 0), var(--el-edge-pos-4, 0 0),
    var(--el-bg-pos-1, 0 0), var(--el-bg-pos-2, 0 0), var(--el-bg-pos-3, 0 0), var(--el-bg-pos-4, 0 0),
    var(--el-float-pos-1, 0 0), var(--el-float-pos-2, 0 0), var(--el-float-pos-3, 0 0), var(--el-float-pos-4, 0 0);
  background-repeat:
    var(--el-corner-rep-1, no-repeat), var(--el-corner-rep-2, no-repeat),
    var(--el-edge-rep-1, no-repeat), var(--el-edge-rep-2, no-repeat), var(--el-edge-rep-3, no-repeat), var(--el-edge-rep-4, no-repeat),
    var(--el-bg-rep-1, no-repeat), var(--el-bg-rep-2, no-repeat), var(--el-bg-rep-3, no-repeat), var(--el-bg-rep-4, no-repeat),
    var(--el-float-rep-1, no-repeat), var(--el-float-rep-2, no-repeat), var(--el-float-rep-3, no-repeat), var(--el-float-rep-4, no-repeat);
}
```

> 缺主合成块的背景模板在画布上**不显示**（引擎 BASE_CSS 无主合成）。这是让画布工作的前提，不要为了"简洁"删掉。

### 3.2 伪元素类（文本类，按 §1.4 占指定伪元素）
```css
.gallery-card[data-style-element-float="tamagotchi_label"]::before {
  content: "TAMAGOTCHI";
  position: absolute; top: 5px; left: 50%; transform: translateX(-50%);
  font-size: 10px; letter-spacing: 1px; color: var(--card-accent);
  font-family: monospace; pointer-events: none; z-index: 3;
}
```
规则：`position:absolute`（卡片已 `position:relative`）；`z-index:3`；`pointer-events:none`；**不要**在伪元素类写 `background-image`（污染画布）；`content` 用固定字面量。

### 3.3 正交类（不抢背景/伪元素）
```css
/* stamp_perforation：mask 四边镂空齿孔。每张遮罩必须用 100% 维度瓦片铺满整卡，
   否则只覆盖边缘条 → mask-composite:intersect 把整卡内部判为「未覆盖=透明」→ 卡片整体消失。 */
.gallery-card[data-style-element-edge="stamp_perforation"] {
  --sp-r: 4px; --sp-g: 13px;
  -webkit-mask:
    radial-gradient(circle var(--sp-r) at 50% 0,    #0000 96%, #000) repeat-x 0 0 / var(--sp-g) 100%,
    radial-gradient(circle var(--sp-r) at 50% 100%, #0000 96%, #000) repeat-x 0 0 / var(--sp-g) 100%,
    radial-gradient(circle var(--sp-r) at 0 50%,    #0000 96%, #000) repeat-y 0 0 / 100% var(--sp-g),
    radial-gradient(circle var(--sp-r) at 100% 50%, #0000 96%, #000) repeat-y 0 0 / 100% var(--sp-g);
  -webkit-mask-composite: source-in, source-in, source-in;
          mask:
    radial-gradient(circle var(--sp-r) at 50% 0,    #0000 96%, #000) repeat-x 0 0 / var(--sp-g) 100%,
    radial-gradient(circle var(--sp-r) at 50% 100%, #0000 96%, #000) repeat-x 0 0 / var(--sp-g) 100%,
    radial-gradient(circle var(--sp-r) at 0 50%,    #0000 96%, #000) repeat-y 0 0 / 100% var(--sp-g),
    radial-gradient(circle var(--sp-r) at 100% 50%, #0000 96%, #000) repeat-y 0 0 / 100% var(--sp-g);
          mask-composite: intersect;
}
.gallery-card[data-style-element-edge="notched_corner"] {
  clip-path: polygon(0 0, calc(100% - 14px) 0, 100% 14px, 100% 100%, 0 100%);
}
```

## 4. 位置参数（锚点定位）

同一装饰贴任意角/边，无需另建 DB 条目。`style_json.element` 加位置字段，引擎注入 CSS 变量，一份模板覆盖 8 锚点。

**8 锚点**：四角（top-left / top-right / bottom-left / bottom-right）+ 四边居中（top-center / right-center / bottom-center / left-center）。
**字段**（缺省 `'native'` = 沿用模板原生位置）：`corner_badge_pos` / `floating_deco_pos`（8 锚点）；`edge_deco_pos`（仅四角）。

**模板消费写法**：
- **背景型**（circle_stamp / dot_status / scatter_dots）：位置变量改 `var()` 兜底——`--el-corner-pos-1: var(--el-corner-anchor-pos, top 6px right 6px);`
- **伪元素型**（corner_ribbon ::after / tamagotchi_label ::before）：`top/right/bottom/left/transform` 全走变量，原生兜底。
  - `transform` 兜底必须是合法 `translate(0,0)`，**绝不可 `none`**（混入 `none` 整条声明失效）。
  - corner_ribbon 朝向：四角必须**镜像**非平移；`transform: var(--el-corner-pos-tf, translate(0,0)) rotate(45deg);`（左上/右下→`-45deg`；四边→`0/90deg`）。
- **隔离层型**（floating_circle `.card-deco-layer::before`）：`top/right/bottom/left/transform` 全走 `--el-float-pos-*`，原生兜底卡内右下角。

**偏移量设计期固定**：锚点决定贴哪角，离角多远由各模板 `var()` 兜底值定（移动后统一 12px）。

**方向性元素**：`art_deco_diamond`（满宽条带，无"角"）不参与切换；`page_fold` 移到对角需翻转渐变角（`--pf-angle`：top-left=135deg / bottom-left=45deg / bottom-right=315deg / 右上=225deg），四边居中回落原生。

## 5. 多组件组合规则（客观约束）

### 5.1 各子维度独占范围
| 子维度 | 占用资源 | 独占范围 |
|---|---|---|
| `corner_badge` | 14 槽画布 + 伪元素/clip | corner-1,2（背景型）/ `::after`（ribbon）/ `::before`（label）/ clip（`page_fold`、`notched_corner`） |
| `edge_deco` | 14 槽画布 + mask/clip | edge-1..4（bracket/tape）/ mask（stamp_perforation）/ clip（notched_corner） |
| `bg_pattern` | 14 槽画布 | bg-1..4 |
| `floating_deco` | 14 槽画布（scatter_dots）或隔离层（floating_circle） | float-1,2（scatter_dots 走画布）；floating_circle 走 `.card-deco-layer::before`（**不占画布 float 槽**） |
| 文本类（ribbon/label/diamond） | 伪元素 | `.gallery-card::after`(ribbon) / `::before`(label) / `.card-deco-layer::before+::after`(diamond) |

### 5.2 安全组合矩阵
| 组合 | 是否安全 | 说明 |
|---|---|---|
| bg_pattern × corner_badge(背景型) | ✅ | 各占 bg / corner 槽，契约共存 |
| bg_pattern × floating_deco(scatter_dots) | ✅ | 各占 bg / float 槽 |
| bg_pattern × floating_deco(floating_circle) | ✅ | 圆在隔离层，与画布正交，永不争 |
| corner_ribbon × tamagotchi_label | ✅ | 分占 `::after` / `::before` |
| corner_ribbon × art_deco_diamond | ✅ | ribbon=`::after`，diamond=`.card-deco-layer`，解耦 |
| 任意背景 × 任意文本类 | ✅ | 画布 vs 伪元素正交 |
| 两个装饰抢同一伪元素 | ❌ | 后者覆盖前者，需错开或改造 |
| 两个背景装饰同卡且其一偏离契约（缺主合成/夹裸字） | ❌ | 层叠抹掉另一组图层 |

### 5.3 仲裁策略（引擎实际行为）
1. **画布层（background-*）**：同特异性、源码顺序后者胜属性；因主合成逐字一致，结果正确（只要都守契约）。违约者或被违约者整组图层异常。
2. **伪元素层**：同一伪元素被两条规则命中 → 同特异性后者胜，表现为一个装饰覆盖另一个（不报错）。文本类必须按 §1.4 分配表各占其位。
3. **隔离层（floating_circle）**：独占 `.card-deco-layer::before`，因 `floating_deco` 单选维度互斥，结构上不可能被其它装饰争用。

### 5.4 单卡装饰总数上限
- 背景类不限量（受 §1.3 契约保护）。
- 文本类最多同时 3 个。
- 单卡装饰总数建议 ≤ 5（corner/bg/edge/float + 文本合计）；结构性 header_deco/side_accent/divider 不计入。
- 硬约束仅伪元素 4 槽（卡片根 `::before`/`::after` 各一 + `.card-deco-layer` `::before`/`::after` 各一）。

## 6. 方向性元素「对角镜像」原则

凡是"贴角/沿边"的方向性装饰（`page_fold` / `corner_ribbon` / `notched_corner` / `art_deco_diamond`），移到对角**必须镜像而非平移**：
- ↘↖ 对角（右上/左下）用**正向**；↙↗ 对角（左上/右下）用**反向**（翻角：左上 `135deg`/右下 `315deg`；丝带：左上/右下 `rotate(-45deg)`）。
- 四边居中：丝带长边**平行**于所在边（顶/底边→横 `0deg`、左/右边→竖 `90deg`）。
- 摆放错（平移不镜像）症状：丝带变贯穿卡身对角斜杠；翻角折痕翻到卡外。

## 7. 入库硬规则清单（CSS 编写）

1. 选择器必须 `.gallery-card[...]`（漏前导点整条静默失效、不报错）。
2. 背景类必带逐字一致 14 槽主合成块（机械复制 §3.1 契约块），禁止手改/缺失。缺主合成的模板在画布上不显示。
3. 只 `SET` 自己组的 `--el-*` 槽位变量，绝不跨组写槽（如 bg 装饰禁止写 `--el-float-*`）。
4. 颜色只引用 `--card-bg/-text/-accent/-muted`（及 `-rgb`），禁止硬编码 hex。
5. 主合成块里 `var()` 之外不得出现任何裸 CSS 关键字（如多拼一个 `repeat`）——整条 `background-*` 会回退默认 `repeat` 导致平铺。兜底字面量（`none`/`auto`/`no-repeat`）只允许出现在 `var()` 第二参数内。
6. 文本类 `content` 用固定字面量，禁两参 `attr()`（不被浏览器支持）。
7. 卡片 `overflow:hidden`，丝带等装饰锚定卡内勿外推（否则被裁掉）。
8. 不用 `!important`。

## 9. 入库 SQL 模板

### 9.1 维度组件入库（通用）
```sql
-- <dim> 取 layout/typo/border/deco/effect/element；<sub_dim> 取对应子维度
insert into style_<dim>_options (sub_dim, value, label, description, css_template, sort_order, is_enabled)
values ('<sub_dim>', '<value>', '<中文标签>', '<效果描述>', '<完整CSS>',
  (select coalesce(max(sort_order),0)+1 from style_<dim>_options where sub_dim='<sub_dim>'), true);
```

### 9.2 改现有组件 CSS（幂等 fix）
```sql
update style_element_options set css_template = '<完整CSS>' where id = <id>;  -- id 见 §8
```

### 9.3 配色入库（harmony_palette 需给种子色）
```sql
insert into style_palette_options (value, label, sub_dim, bg, text_color, accent, muted, extra_colors, description, sort_order)
values ('analogous_teal_violet','青紫邻近','harmony_palette',
  '#0D9488','#A78BFA','#0D9488','#A78BFA',
  '{"accent_2":"#C084FC","bg_secondary":"#134E4A"}', '青色到紫色邻近过渡',
  (select coalesce(max(sort_order),0)+1 from style_palette_options where sub_dim='harmony_palette'));
```

### 9.4 容器组入库（给 key 字段）
```sql
insert into style_container_group_options
  (group_code, group_name, category, description, layout_ref, repeat_mode,
   field_slot_map, slot_deco_map, layout_slot_map, extra_css, sort_order, is_enabled)
values ('cg_my_layout','我的布局','creative','说明',
  '2col_equal','once',

  '{"slot_a":"deco:bubble_style.wechat_left"}'::jsonb,
  '{"slot_a":1,"slot_b":2}'::jsonb,
  '.container-group.cg_my_layout{...}',
  (select coalesce(max(sort_order),0)+1 from style_container_group_options), true);
```

## 10. 验证流程（入库前必做）

1. 用 `capsule-preview.html`（实时预览）或 `gallery.html`（瀑布流）加载目标卡片，核对：① 独立显示 ② 四者叠加（corner+bg+edge+float 同开）③ 文本类与背景类共存。
2. 新 bg_pattern 同开 `floating_circle` 时，浮动圆**必须仍能随 `floating_deco_pos` 移动、不消失、不平铺**；并核对主合成块逐字一致、无裸关键字。
3. 确认无 `!important`、无硬编码 hex、无漏前导点、无跨组写槽。
4. 产出 SQL 交用户执行；用户执行后硬刷新预览页（Ctrl+Shift+R）确认线上生效。
