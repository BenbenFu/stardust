# 卡片 style_json 拼装手册（Agent 专用 · 精简版）

> **读者**：只需「从现有组件里挑 → 拼出一份合法 `style_json`」的 agent。**不写 CSS、不写 SQL、不碰数据库。**
> **目标**：拿到设计主题 → 从现有组件挑 → 拼 `style_json` →（可选）存 `STYLE_POOL`。
> **要设计新元素 / 改现有组件的 CSS？本手册不含这些，请读同目录《元素入库手册.md》。**
>
> **设计基调（重要）**：现有组件是**默认起点，不是枷锁**。优先复用、大胆组合是对的；但若现有组件与主题**明显不搭**，不要硬凑一个近似件——直接切到《元素入库手册》提交「新元素请求」。复用是效率手段，不是限制你表达主题的理由。

---

## 0. 三句话讲清原理（不用读代码）

1. **卡片 = 日记数据 + `style_json` + 数据库里的 `css_template`。** 引擎把 `style_json` 翻译成 `data-*` 属性挂到卡片 DOM，再从数据库维度表查出对应 CSS 注入。样式零硬编码，全由数据库驱动。
2. **你只产 `style_json`，不写 CSS。** 每个字段的取值必须是数据库某张「维度选项表」里**已存在的 `value`**（见第 3 节）。引擎只认这些 `value`，认不到就忽略。
3. **想要数据库里没有的效果？** 不要自己写 CSS 塞进 `style_json`。按《元素入库手册》提交「入库请求 SQL」，等用户审核执行后进库，之后所有人都能用。

渲染链路一句话：`style_json → renderStyleJson() → data-* + CSS 变量 → buildCardHtml() → <a class="gallery-card"> → injectDynamicStyles() 注入 DB css_template`。

## 1. style_json 权威结构（引擎认的就是这个）

引擎实际读取的**完整 schema**（与 `style-engine.js` 的 `DEFAULT_STYLE_JSON` 一致）。**缺省的 key 一律按默认值处理**，所以你只写要改的字段即可。

```jsonc
{
  "palette": {
    "harmony": "mono_grey",          // 色相组合（必选，见 §3.1）
    "tone": "light_standard",        // 明暗调性（见 §3.1）
    "slot": "original"               // 四色槽位映射（见 §3.1）
  },
  "layout": {
    "grid": "single",                // 网格结构（见 §3.2）
    "flow": "horizontal",            // 书写方向 horizontal/vertical/mixed
    "flow_vertical": [],             // mixed 流下哪些字段竖排：["title","date",...]
    "slot_assignment": { "a": "date", "b": "title", "c": "highlights", "d": "capsule" },
    "density": "normal",             // sparse/normal/dense
    "block_align": "left",           // 块级对齐 start/center/end/stretch
    "inline_align": "left",          // 行内对齐 left/center/right/stretch
    "spacing_scale": "md"            // 全局间距基准 xs/sm/md/lg/xl
  },
  "typo": {
    "font_family": { "title":"FontYuan", "date":"FontYuan", "capsule":"FontYuan", "highlights":"FontYuan" },
    "weight_gradient": "balanced",   // 字重梯度
    "size_scale": "petite",          // 字号梯度
    "alignment_mode": { "title":"inherit", "date":"inherit", "capsule":"inherit", "highlights":"inherit" },
    "spacing_tightness": { "title":"normal", "date":"normal", "capsule":"normal", "highlights":"normal" },
    "text_decoration": { "title":[], "date":[], "capsule":[], "highlights":[] }  // 数组，可多选
  },
  "border": {
    "radius_size": "none", "border_width": "none",
    "border_style": "solid", "border_shadow": "none"
  },
  "deco": {
    "bubble_style": "none", "tag_style": "none", "avatar_style": "none", "avatar_pos": "side",
    "boxes": [], "box_radius": 8, "box_gap": 12, "action_style": "none"
  },
  "element": {
    "header_deco": "none", "header_text": "", "header_width": 6,
    "header_text_family": "", "header_text_size": "", "header_text_align": "",
    "side_accent": "none", "side_text": "", "side_width": 8, "side_position": "left",
    "side_text_family": "", "side_text_size": "", "side_text_align": "",
    "band_inset": true, "divider": "none",
    "corner_badge": "none", "bg_pattern": "none", "edge_deco": "none", "floating_deco": "none",
    "corner_badge_pos": "native", "floating_deco_pos": "native", "edge_deco_pos": "native"  // 位置微调，见 §3.7
  },
  "effect": {
    "filter_self":  { "title":"none", "date":"none", "capsule":"none", "highlights":"none" },
    "filter_backdrop": { "title":"none", "date":"none", "capsule":"none", "highlights":"none" },
    "transform":    { "title":"none", "date":"none", "capsule":"none", "highlights":"none" },
    "animation":    { "title":"none", "date":"none", "capsule":"none", "highlights":"none" }
  },
  "container_group": "none",
  "container_groups": []
}
```

**两个关键约定（写错不报错但会不对）：**
- **per-element 维度**（typo 的 `font_family`/`alignment_mode`/`spacing_tightness`/`text_decoration`，以及 effect 全部四项）：value 可写**字符串**（四字段同值）或**对象** `{title,date,capsule,highlights}`（逐字段不同）。要统一写字符串，要差异化写对象。
- `text_decoration` 是**数组可多选**，如 `["prefix_bar","gradient_text"]`。
- `alignment_mode` 默认 `inherit` = 跟随 `layout.inline_align`；只有想让某字段单独改方向时才显式写。

## 2. 字段与槽位模型（先懂骨架再拼皮）

卡片四个核心字段：**date / title / highlights / capsule**，经 `layout.slot_assignment` 摆进 `a/b/c/d` 四网格槽。

> **capsule 是什么？** 渲染的是日记的**扭蛋机风格名**（`d.capsuleName`，12 台扭蛋机之一），是卡面上代表风格主题的小标识。把它当**与 title/date 同级的短文本槽**排版即可，很适合用 `weight_gradient: capsule_heavy` 或单独 `alignment_mode` 让它跳出来。

- 改 `slot_assignment` 重排四字段位置；`highlights` 是数组渲染成多条，其余单值。
- Deco Box / effect / 字段级 typo 都针对这四字段（或 `global` 整卡）。
- 容器组（`container_groups`）只作用在 highlights 作用域，不重复渲染四个主槽。

## 3. 组件总览（可选 value 清单 = 你的「素材库」）

> 每个条目 `value='xxx' | 中文标签 | 效果`。直接填 `value` 字符串即可。带 ★ 高频、优先尝试。

### 3.1 配色 palette
- **harmony（色相，38 个）**：邻近 analogous（蓝紫/蓝青/绿青/青柠黄/橙黄/紫粉/红橙/玫瑰红）、撞色 complementary（勃艮第米/炭灰琥珀/钴蓝沙/深林珊瑚/爱马仕橙灰/克莱因蓝白/藏青奶黄/荧光黄黑）、分裂互补 split（6）、三角色 triadic（6）、四方色 tetradic（4）、单色 mono（蓝/绿/灰/橙/紫/红）。
- **tone（明暗，6 个）**：`raw_seed` 原色直出 / `light_standard` 浅调标准 / `light_soft` 浅调柔和 / `medium_strong` 中调强烈 / `dark_standard` 深调标准 / `dark_deep` 深调深邃。
- **slot（四色排布，7 个）**：`original` / `swap_bg_text` / `swap_bg_acc` / `swap_text_acc` / `shift_fwd` / `shift_bwd` / `cross_swap`。

> 配色只用 `harmony`/`tone`/`slot` 三个 key 选，**绝不在 style_json 里写颜色十六进制**——换一套 palette 整卡配色自动联动。配色如何映射到 CSS 变量（以及为什么不能在 CSS 里硬编码颜色）见《元素入库手册》§3。

### 3.2 布局 layout
- **grid（17 个）**：`single` 单栏★ / `2col_equal` / `2col_left_wide` / `2col_right_wide` / `2col_left_narrow` / `2col_right_narrow` / `3col_equal` / `3col_left_focus` / `3col_right_focus` / `sidebar_left` / `sidebar_right` / `sidebar_both` / `top_split` / `bottom_split` / `hero`★ / `inverted` / `timeline`★（自带左侧轴线）。
- **flow**：`horizontal` / `vertical` / `mixed`（配 `flow_vertical` 指定竖排字段）。
- **density**：`sparse` / `normal` / `dense`。
- **block_align**：`start`/`center`/`end`/`stretch`。**inline_align**（全局默认）：`left`/`center`/`right`/`stretch`。**spacing_scale**：`xs`/`sm`/`md`/`lg`/`xl`。

### 3.3 排版 typo（per-element）
- **font_family（9 个，均为 `Font*` 键）**：`FontHei` 黑体★ / `FontSong` 宋体 / `FontYuan` 圆体 / `FontKai` 楷体 / `FontMono` 等宽 / `FontCreative` 创意 / `FontHand` 手写（笔画花，长段慎用）/ `FontCalli` 书法 / `FontCartoon` 卡通。
- **weight_gradient（6）**：`high_contrast` / `balanced`★ / `soft` / `neutral` / `capsule_heavy` / `bold_heavy`。
- **size_scale（5）**：`headline_impact` / `balanced_read` / `compact_dense` / `petite`★ / `large_comfort`。
- **alignment_mode（5）**：`inherit` / `left` / `center` / `right` / `stretch`。
- **spacing_tightness（4）**：`loose` / `normal` / `tight` / `dense`。
- **text_decoration（可多选，16）**：`none` / `underline_solid` / `underline_wavy` / `underline_dashed` / `strikethrough` / `prefix_dot` / `prefix_bar`★ / `prefix_number` / `capsule_tag` / `capsule_badge` / `uppercase` / `italic` / `gradient_text`★ / `text_stroke` / `text_glow` / `text_3d`。

### 3.4 边框 border
- **radius_size（7）**：`none` / `xs`(2) / `sm`(4) / `md`(8)★ / `lg`(12) / `xl`(20) / `full`(9999)。
- **border_width（5）**：`none` / `hairline`(0.5) / `thin`(1) / `medium`(2) / `thick`(4)。
- **border_style（4）**：`solid` / `dashed` / `dotted` / `double`。
- **border_shadow（5）**：`none` / `soft` / `soft_small` / `inset` / `hard_offset`。

### 3.5 装饰 deco
- **bubble_style（5）**：`none` / `wechat_left` / `wechat_right` / `imessage_rounded` / `quote_bubble`。
- **tag_style（8）**：`none` / `capsule_fill` / `capsule_outline` / `badge_circle` / `stamp_dashed` / `corner_cut` / `mini_badge` / `dot_label`。
- **avatar_style（6）**：`none` / `circle_solid` / `circle_outline` / `square_rounded` / `initial_label` / `square_solid`。
- **action_style（7）**：`none` / `icon_text_btn` / `icon_only_btn` / `text_link` / `solid_btn` / `ghost_btn` / `icon_text_vertical`。
- **boxes（★核心，见 §3.6）**。

### 3.6 ★ Deco Box（最灵活的拼装件）
`deco.boxes` 是有序数组，每个盒子 = 对字段/内容的嵌套包裹层，可多层叠加：
```jsonc
"boxes": [
  { "style": "gradient_linear", "target": "highlights" },
  { "style": "glass_standard",  "target": "highlights" },
  { "style": "float_card",      "target": "title" },
  { "style": "outline_border",  "target": "global", "coincide": true }
]
```
- `style` ∈ 下列；`target` ∈ `global`/`title`/`date`/`capsule`/`highlights`；可选 `coincide:true` 让盒子与内层边缘重合（padding:0）。
- 同区域可叠多个盒子，数组顺序 = 由外到内。`deco.box_radius`/`deco.box_gap` 统一控制。

**box_style（14）**：`solid_fill` / `outline_border` / `left_bar_quote` / `code_dark` / `dashed_cutout` / `sticky_note` / `tape_note` / `float_card` / `glass_standard` / `liquid_glass` / `gradient_linear` / `gradient_flow` / `gradient_radial` / `none`。

> 想"浮起"→ `float_card`；"玻璃感"→ `glass_standard`/`liquid_glass`（配 effect 的 `backdrop_blur`）；"手账拼贴"→ `sticky_note`/`tape_note`；"代码感"→ `code_dark`。

### 3.7 元素装饰 element（整卡级装饰）
- **header_deco（7）**：`none` / `solid` / `gradient` / `blink`★ / `diagonal` / `breathing` / `scanline`。
- **side_accent（8）**：`none` / `solid` / `gradient` / `line_number_column`★ / `notebook_binding` / `diagonal` / `breathing` / `scanline`。
- **divider（6）**：`none` / `thin_solid` / `double_line` / `dotted_line` / `gradient_line` / `char_asterisk`。
- **corner_badge（5）**：`none` / `circle_stamp` / `page_fold` / `corner_ribbon` / `dot_status`。
- **bg_pattern（6）**：`none` / `dot_grid` / `fine_grid` / `horizontal_lines`★ / `gradient_overlay` / `terminal_scanlines`★ / `starfield`（星空）。
- **edge_deco（5）**：`none` / `stamp_perforation` / `bracket_frame` / `notched_corner` / `tape_stripe`。
- **floating_deco（5）**：`none` / `floating_circle` / `scatter_dots` / `art_deco_diamond` / `tamagotchi_label`。
- **自定义文字**：`header_text`/`side_text` 填内容；`*_text_family`/`*_text_size`/`*_text_align` 控制排印。
- **band_inset**：`true` 色条内缩留白 / `false` 色条贴边满边。`header_width`/`side_width` 控制条粗细(px)。

> **位置微调**：同一装饰可贴不同角/边，无需另建条目——设 `corner_badge_pos` / `floating_deco_pos`（8 锚点：四角 + 四边居中）或 `edge_deco_pos`（仅四角）。具体锚点词汇、镜像规则、怎么写 CSS 见《元素入库手册》§5。
> **组件不够贴主题？** 现有 `value` 里没有合适视觉时，**不要硬凑**。按《元素入库手册》提交新元素请求（含 CSS + SQL），用户审核执行后进库，你后续就能直接引用。

### 3.8 特效 effect（per-element，四字段各自独立）
四项都按 `{title,date,capsule,highlights}` 设值，可字符串统配或对象分设。
- **filter_self（11）**：`none` / `blur_sm` / `blur_md` / `drop_shadow_soft` / `drop_shadow_hard` / `grayscale` / `sepia` / `brightness_high` / `contrast_high` / `saturate_high` / `hue_rotate_90`。
- **filter_backdrop（3）**：`backdrop_blur_sm`(8px) / `backdrop_blur_md`(16px) / `backdrop_blur_lg`(32px)（与 filter_self 可并存）。
- **transform（7）**：`none` / `rotate_left_sm` / `rotate_right_sm` / `scale_up_sm` / `scale_down_sm` / `translate_up_sm` / `skew_left_sm`。
- **animation（8）**：`none` / `fade_in` / `slide_up_in` / `pulse_slow` / `float_slow` / `spin_slow` / `bounce_small` / `glow_pulse`。

### 3.9 容器组 container_groups（社交/评论/拼贴专用）
数组，把若干「横向带模板」compose 进 highlights 区（**不替换四主槽**）。`container_groups: ["cg_chat_message_left", "cg_chat_message_right"]`。
- **per_line 组**按数组顺序排成循环队列，每条 highlight 行由队列下一个组承包；**once 组**整段只渲染一次（在首个 per_line 前→最前，之后→最后）。
- 现有 9 个：`cg_chat_message_left`/`cg_chat_message_right`（per_line 左右气泡）、`cg_comment_item`/`cg_comment_sub`（per_line 评论）、`cg_social_full_card`（once 整卡）、`cg_social_header`（once 头部）、`cg_social_interact_bar`（once 赞评转）、`cg_sticky_two`/`cg_sticky_three`（once 双/三便签）。
- 容器组内部装饰（气泡/头像/操作）由数据库预设，**你 style_json 不能逐槽改**；想控制内部装饰 → 挑合适的 CG，或按《元素入库手册》提新容器组。

## 4. 设计工作流（照着做）

1. **定主题**：想清这张卡要什么气质（赛博/文学/社媒/杂志/手账/代码…）。
2. **选配色**：§3.1 挑 harmony，再定 tone/slot。先定基调。
3. **定骨架**：§3.2 挑 `grid`；要不要竖排 `flow`；要不要 `container_groups`。
4. **挑皮**：逐维度从 §3.3~§3.9 挑组件。**多试 Deco Box 叠加 + 毛玻璃/渐变 + 背景纹理 + 顶/侧栏装饰**的组合，最容易出"惊艳不撞车"的效果。
5. **差异化字段**：用 per-element 让某字段跳出（如标题 `FontHei`+`bold_heavy`，正文 `FontSong`）。
6. **只写要改的字段**，其余交默认。
7. **（组件不够？）提新元素**：现有 `value` 没有贴合主题的视觉时，**别将就**——按《元素入库手册》提交新元素请求。
8. **（可选）存库**：成型 `style_json` 作为 `STYLE_POOL` 记录，方便复用与 Gallery 展示（见 §5）。

## 5. 存入 STYLE_POOL（让设计可被复用/展示）
`STYLE_POOL` 字段：`name`(唯一) / `category` / `desc` / `style_json`(JSONB) / `active`。分类：`code/tech/work/life/social/creative/format/media/misc/fiction/roleplay`。

> ⚠️ 现有 334 条中大量是**旧版 schema**（不被当前引擎识别）。新设计务必用本手册 §1 的 v2 schema，入库前自查 key 是否完全对应。

```sql
insert into "STYLE_POOL" (name, category, desc, style_json, active)
values ('赛博终端_霓虹', 'tech', '黑底荧光+扫描线+行号栏，硬核终端风',
  '{"palette":{"harmony":"comp_neon_black","tone":"dark_deep","slot":"original"},"layout":{"grid":"single","density":"dense"},"typo":{"font_family":"FontMono","weight_gradient":"bold_heavy","size_scale":"compact_dense"},"border":{"radius_size":"none","border_width":"thin","border_style":"solid","border_shadow":"none"},"deco":{"boxes":[{"style":"gradient_linear","target":"highlights"}],"box_radius":0},"element":{"header_deco":"blink","side_accent":"line_number_column","bg_pattern":"terminal_scanlines","band_inset":false},"effect":{"filter_backdrop":{"title":"backdrop_blur_md","date":"none","capsule":"none","highlights":"none"},"animation":{"title":"none","date":"none","capsule":"none","highlights":"none"}}}'::jsonb,
  true);
```

## 6. 约束与坑（务必看）

1. **只引用已存在的 `value`。** 拼错/捏造的 value 引擎直接忽略，卡片变默认样，你以为生效了其实没。不确定先查本手册 §3。
2. **你无数据库写权限**：新增/修改组件只能产出 SQL 交用户执行（写法见《元素入库手册》）。
3. **per-element 维度**写成对象才有逐字段差异；写字符串 = 四字段同值。
4. **对齐三层级**（易混）：`layout.block_align`(块) → `layout.inline_align`(行内，全局默认) → `typo.alignment_mode`(字段级，默认 `inherit`)。想让某字段单独改方向，只动 `alignment_mode`。
5. **Deco Box 叠加顺序** = 数组由外到内；`coincide:true` 才与内层边缘重合。
6. **容器组只渲染 highlights 作用域**，不重渲染 date/title/capsule 四槽。整卡级需求用 `boxes` 的 `target:'global'`。
7. **毛玻璃需 backdrop-filter 支持**；`filter_self` 与 `filter_backdrop` 已解耦可并存。
8. **缓存**：前端改了 DB 模板会自动下次加载重拉，你设计 style_json **不需要 bump `?v=`**（那是改引擎代码才要的）。
9. **STYLE_POOL 旧条目多为旧 schema**，新设计必须遵循本手册 §1 v2 结构。
10. **设计要大胆**，但大胆建立在「复用现有组件」之上——复用是默认起点，组件不搭时则提新元素（《元素入库手册》），别硬塞 CSS。

## 8. data-attr 速查（调试用）
引擎把 `style_json` 字段映射成 DOM `data-*` 属性，由 DB css_template 选择器命中。常用：`layout.grid→data-style-layout-grid`、`typo.font_family.title→data-style-typo-font-family-title`、`deco.boxes→[data-style-deco-box="X"]`、`element.header_deco→data-style-element-header`、`element.side_accent→data-style-element-side`、`effect.filter_self.title→data-style-effect-filter-title`。完整映射见 `style-engine.js` 的 `ATTR_MAP`。**设计时不需关心——value 在 §3 里引擎就会自动接上。**
